# ResumeAI — AI Resume Analyzer (Mock)

A React + Vite single-page app that mimics an AI-powered resume analyzer: upload a resume, get an ATS score, keyword matching, section-by-section feedback, and prioritized improvement suggestions — all in a polished dashboard UI.

> **Note:** This is a **local preview / mock build**. The "AI analysis" is generated by a mock function (`callClaudeAPI`) that returns realistic fake data after a short simulated delay. No real API calls are made and no resume content is actually read or sent anywhere.

## Features

- **Dashboard** — overview stats and quick access to recent reports
- **Analyze Resume** — upload a `.pdf` or `.docx` file, enter a target job role, and get a simulated analysis with a step-by-step progress indicator
- **Results view** — overall ATS score, sub-scores (formatting, keywords, skills, experience, etc.), strengths/weaknesses, found vs. missing keywords, and a skills radar
- **Section-by-section breakdown** — per-section score, status, issues, and suggestions (Contact Info, Summary, Skills, Experience, Projects, Education)
- **Prioritized improvements** — High / Medium / Low priority action items
- **My Reports** — history of past analyses, revisit or delete them
- **Resume Builder** — basic starter tool for building a resume
- **Light/Dark theme toggle**

## Getting Started

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
npm install
```

### Run the dev server

```bash
npm run dev
```

Then open the printed local URL (typically `http://localhost:5173`) in your browser.

### Build for production

```bash
npm run build
```

Outputs a production build to `dist/`.

### Preview the production build

```bash
npm run preview
```

### Lint

```bash
npm run lint
```

## Connecting a Real Backend

The mock analysis function is isolated at the top of `src/AIResumeAnalyzer.jsx`:

```js
async function callClaudeAPI(systemPrompt, userMessage, onStream) { ... }
```

The original version of this function called `api.anthropic.com` directly from the browser. That only works inside Claude.ai's artifact sandbox, which injects an API key server-side — in a standalone app it will fail with a CORS or missing-key error.

To wire up real resume analysis:

1. Stand up a small backend endpoint (Node, Python, etc.) that calls the Anthropic API server-side, where your API key can be kept secret.
2. Replace the body of `callClaudeAPI` with a `fetch()` call to your new endpoint, forwarding the resume text/role and returning the JSON response in the same shape the mock currently produces (see the `mock` object in the function for the expected schema).
3. No other UI code should need to change, since the rest of the app just consumes the parsed JSON result.

## Privacy Note (as shown in the app)

The Settings page states that resumes are processed and not retained beyond the current session. Since this build is a front-end mock, no resume content is actually uploaded, parsed, or stored anywhere — it exists only in memory in the browser tab.
